# Project-2-Website-Scrapping

## Purpose of the Project

This project analyzes NFL offensive performance over the past five seasons using team-level statistics scraped from Pro Football Reference. The goal is to uncover trends and key insights into scoring, yardage, and discipline (penalties) to better understand how teams perform offensively and what factors may impact scoring.

## Data Science Questions
There were 5 data science questions I answered during this project:
1. What is the average points scored per year?
2. Which team scored the most points in each year?
3. What is the correlation between penalties and points scored?
4. How has total yardage changed over the years?
5. Which team scored the most points per game over the past 5 seasons?

## Project Files
You can find 1 project file in this GitHub repository:
**James McGinty - Project 2.ipynb** is a Jupyter Notebook that scrapes team offensive statistics from Pro Football Reference, cleans the data, and performs data analysis. The notebook answers all five data science questions using Python, Pandas, and Seaborn. Plots include data labels, appropriate styling, and clear titles to support the analysis.

## Data Source
All NFL team data was scraped from [Pro Football Reference](https://www.pro-football-reference.com/).
